# Психологічні методики

Кожна методика живе у власній папці:

- `Adaptability200/` — Адаптивність-200 (ключі, норми, scoring)
- `Weapon/` — Тест «Зброя»
- `SuicideRisk/` — СР-45 / суїцидальний ризик
- `Horska/` — методика Горської
- `Assinger/` — тест А. Ассингера (оцінка агресивності)
- `Npna/` — особистісний опитувальник «НПН-А» (нервово-психічна нестійкість — акцентуація)
- `Common/` — спільні контракти (за потреби)

Результати працівників у системі окремо:
**Підрозділ → Працівник → Тест → Проходження (TestAttempt)**.
